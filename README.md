# Jhekasoft site

## Prepare

Start [jhekasoft-api](https://github.com/jhekasoft/jhekasoft-api) (module [cv](https://github.com/jhekasoft/jhekasoft-api/tree/master/modules/cv)).

Deprecated alternative: ~~[Jhekasoft API](https://github.com/jhekasoft/jhekasoft-api-old)~~.

## How to use

Install it and run:

```sh
npm install
npm run dev
```

## Deploy

```sh
npm run export-and-deploy
```
